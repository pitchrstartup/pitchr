# Pitchr

Empty base ready for rebuild.

## What remains

- Next.js app shell
- Basic global styling
- Minimal landing page
- Static placeholder pages for `/discover` and `/leaderboard`

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Notes

- No database layer
- No Prisma schema or migrations
- No ingestion/sync logic
- No internal/admin routes
